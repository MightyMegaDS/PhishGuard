
# PhishGuard

Интерактивный тренажёр по распознаванию фишинга.

## Проблема

Фишинг остаётся одной из наиболее распространённых угроз информационной
безопасности. По данным отраслевых исследований, свыше 90% успешных
кибератак начинаются с фишингового письма или поддельного веб-ресурса.
Основная причина уязвимости пользователей — отсутствие практического
опыта распознавания подобных угроз, а не невнимательность.

## Описание решения

PhishGuard представляет собой тренажёр, в котором пользователь анализирует
примеры электронных писем, веб-страниц и сообщений, после чего выносит
суждение: является ли представленный материал фишинговым. По результатам
каждого задания пользователь получает подробный разбор с указанием
характерных признаков угрозы или их отсутствия.

Планируемые форматы заданий:
- анализ электронных писем;
- анализ URL-адресов и интерфейсов веб-сайтов;
- анализ сообщений в мессенджерах;
- соревновательный режим с таблицей результатов.

## Целевая аудитория

- студенты любых специальностей;
- сотрудники организаций без специальной подготовки в области ИБ;
- широкий круг пользователей сети интернет;
- преподаватели цифровой грамотности и информационной безопасности.

## Текущая стадия

Идея и учебный прототип. В настоящее время ведётся сбор требований
и обратной связи от аудитории. Полноценная разработка начнётся после
валидации концепции.
