# Учебные примеры фишинга

В данной папке размещаются обезличенные учебные примеры фишинговых писем,
веб-страниц и сообщений, собранные от участников проекта.

## Требования к материалам

- Все примеры должны быть обезличены: имена, адреса, номера телефонов,
  адреса электронной почты и иные персональные данные подлежат замене
  на условные обозначения (например, [ИМЯ], [ТЕЛЕФОН], [EMAIL]).
- Публикация реального вредоносного кода или активных фишинговых ссылок
  запрещена.
- Каждый пример должен сопровождаться описанием признаков фишинга.

## Структура файла примера

Каждый пример оформляется в формате Markdown по следующей схеме:

```
# Пример [номер]: [краткое описание]

## Тип
Электронное письмо / Веб-сайт / Сообщение

## Категория
Банк / Маркетплейс / Госсервис / Соцсеть / Другое

## Уровень сложности
Низкий / Средний / Высокий

## Содержание примера
[текст письма или описание сайта в обезличенном виде]

## Признаки фишинга
1. ...
2. ...
3. ...

## Пояснение
[развёрнутый разбор признаков для учебных целей]
```

## Как добавить пример

Откройте Issue с шаблоном «Пример фишинга» и заполните все поля.
После проверки материал будет добавлен в репозиторий.
