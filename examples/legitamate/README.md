# Учебные примеры легитимных писем

В данной папке размещаются обезличенные примеры настоящих (не фишинговых)
писем и сообщений. Они используются в тренажёре для формирования навыка
различения легитимного контента и фишинга.

## Назначение

Тренажёр должен обучать не только распознавать фишинг, но и не ошибочно
принимать за него настоящие письма. Ложные срабатывания снижают доверие
к инструменту и могут привести к нежелательным последствиям.

## Требования к материалам

- Все примеры должны быть обезличены аналогично папке phishing/.
- Публикуются только письма от организаций, которые дали явное
  или подразумеваемое согласие на использование их шаблонов
  в учебных целях (публичные уведомления, типовые рассылки).
- Материалы не должны содержать коммерческой тайны или конфиденциальных
  сведений.

## Структура файла примера

```
# Пример [номер]: [краткое описание]

## Тип
Электронное письмо / Уведомление сервиса / Другое

## Организация (обобщённо)
Банк / Маркетплейс / Госсервис / Соцсеть / Другое

## Содержание примера
[текст в обезличенном виде]

## Признаки легитимности
1. ...
2. ...
3. ...

## Пояснение
[разбор того, почему данное письмо является настоящим]
```

## Как добавить пример

Откройте Issue с шаблоном «Пример фишинга», выберите тип «Легитимное письмо»
и заполните поля. После проверки материал будет добавлен в соответствующую папку.
