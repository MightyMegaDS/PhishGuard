# Дорожная карта PhishGuard

Документ отражает текущее состояние проекта и планируемые этапы развития.
Сроки являются ориентировочными и могут корректироваться по результатам
обратной связи от участников.

## Этап 0 — Валидация концепции (текущий этап)

Цель: убедиться, что идея актуальна и востребована у целевой аудитории.

- [x] Формулирование идеи проекта
- [x] Публикация репозитория и карточки проекта
- [ ] Сбор обратной связи через форму (цель: 20+ ответов)
- [ ] Проведение голосования за приоритетный формат тренажёра
- [ ] Сбор 10+ учебных примеров фишинговых писем от участников
- [ ] Анализ результатов и принятие решения о продолжении разработки

## Этап 1 — Проектирование (планируется)

Цель: определить требования к продукту и спроектировать интерфейс.

- [ ] Составление списка пользовательских историй
- [ ] Разработка прототипа интерфейса в Figma
- [ ] Публикация прототипа для обсуждения
- [ ] Сбор замечаний по интерфейсу
- [ ] Утверждение финального дизайна

## Этап 2 — Разработка прототипа (планируется)

Цель: создать минимально рабочую версию тренажёра.

- [ ] Выбор технологического стека
- [ ] Разработка базового набора заданий (10–20 примеров)
- [ ] Реализация механизма ответа и разбора ошибок
- [ ] Внутреннее тестирование

## Этап 3 — Закрытое тестирование (планируется)

Цель: проверить работоспособность и удобство использования.

- [ ] Набор тестировщиков из числа участников сообщества
- [ ] Проведение тестирования
- [ ] Сбор и анализ отчётов об ошибках
- [ ] Исправление критических недостатков

## Этап 4 — Публичный запуск (планируется)

Цель: открыть доступ к тренажёру для широкой аудитории.

- [ ] Публикация рабочей версии
- [ ] Расширение базы примеров
- [ ] Добавление новых форматов заданий
- [ ] Формирование постоянного сообщества участников

## Как повлиять на дорожную карту

Предложения по изменению приоритетов и новым направлениям принимаются
в разделе Discussions. Задачи с наибольшим числом голосов рассматриваются
в первую очередь.
